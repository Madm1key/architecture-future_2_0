# Future 2.0 Tech Radar

Интерактивная визуализация технологий в формате AOE Technology Radar.

## Требования

- [Node.js](https://nodejs.org/)
- npm

## Установка зависимостей

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run serve
```

Радар будет доступен по адресу: http://localhost:3000/

## Сборка статического сайта

```bash
npm run build
```
