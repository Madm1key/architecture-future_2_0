Существующий стек финтех-домена. Go используется для высоконагруженных сервисов (платежи, транзакции), Java — для банковской логики.

**Бизнес-сценарии:** финтех-домен развивается автономно на своём стеке без влияния на другие домены; банковская лицензия требует изолированного контура.
