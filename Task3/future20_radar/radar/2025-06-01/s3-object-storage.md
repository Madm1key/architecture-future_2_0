Облачное объектное хранилище как основа Lakehouse. Хранит физические файлы данных (Parquet/Iceberg) с многоуровневым тиерингом (hot/warm/cold).

**Бизнес-сценарии:** эластичное масштабирование под рост данных (сотни ТБ) без управления железом (P8); снижение стоимости хранения по сравнению с on-premise DWH.
