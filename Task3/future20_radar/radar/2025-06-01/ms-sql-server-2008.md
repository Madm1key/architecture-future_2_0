Центральное хранилище данных на базе SQL Server 2008. Содержит всю бизнес-логику компании: медицинские карты, финансовую историю, данные по персоналу и инвентаризации.

**Почему выводим:** версия 2008 снята с поддержки Microsoft, высокий риск уязвимостей. Монолитная бизнес-логика в DWH блокирует независимое развитие доменов (P2, P3), отчёты строятся часами (P1).

**Замена:** каждый домен получает собственное хранилище (PostgreSQL); аналитика переносится в Lakehouse (S3 + Iceberg).
