Открытый табличный формат для хранения аналитических данных в S3. Обеспечивает ACID-транзакции, schema evolution и time travel поверх объектного хранилища.

**Бизнес-сценарии:** масштабируемое хранение сотен ТБ аналитических данных без привязки к железу; версионирование таблиц через Project Nessie; быстрая отчётность через Dremio.
